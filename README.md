# XFM Файлы

Файловый менеджер для Android (Kotlin + Jetpack Compose) с темами и поддержкой Shizuku.

## Возможности
- Главная: хранилища, категории, закладки, недавние файлы
- Список / сетка / компактный вид, сортировка, миниатюры, поиск (в т.ч. во вложенных папках)
- Копировать, вырезать, вставить, переименовать (и группой), удалить, корзина с восстановлением
- ZIP: сжатие и распаковка, свойства файла, MD5 / SHA-256
- Текстовый редактор, просмотр изображений с жестами, «Открыть как…»
- Анализ памяти: папки по размеру, крупные файлы, поиск дубликатов
- Темы: 8 цветов, светлая / тёмная / системная, AMOLED, Material You
- Shizuku: Android/data, Android/obb, системные папки, терминал

## Сборка
Push в ветку `main` → GitHub Actions соберёт APK (вкладка Actions → Artifacts → XFM-apk).
Подпись берётся из `app/xfm.jks`, поэтому обновления ставятся поверх без удаления.
